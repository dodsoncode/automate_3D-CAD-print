# Level 0: wiggle a motor
Goal: find out which motor is which. Needs: robot with no legs attached yet, battery on.

1. `on start` > **start walker**. (A sad face means the board is not found. Check the little cable and the switch.)
2. `on button A pressed` > **wiggle** front left hip.
3. Press A. The motor you plugged into channel 0 should wiggle. Label it.
4. Try the other legs and the knee. Write which button wiggles which motor.

Fix-it blocks: if a joint moves the wrong way, use **flip direction**. If a leg stands crooked, use **nudge** a few degrees.
