# "Slice for P1S" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a passcode-guarded, background "Slice for P1S" job to the Image3D Render service and a phone UI for it that ends in a checked `.gcode.3mf` download.

**Architecture:** A Python module (`image3d/slicing.py`) prepares the STL, runs a small Node script (`image3d/slicer/slice_job.js`) that calls the `orcaslicer-addon` engine with pinned Bambu profiles, and verifies the G-code. `server.py` wraps it in an in-memory job queue with three routes. The page adds a panel that polls the job. The engine is installed at Render build time by a script that never fails the build.

**Tech Stack:** Python 3 / FastAPI (existing), Node >= 18 + `orcaslicer-addon@0.1.0`, OrcaSlicer BBL profiles at commit `47a17ad9a33af7871bdbf21935bc2c1a6a5e488f`, vanilla JS page, pytest + Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-p1s-slicing-design.md` (measurements: `docs/2026-11-12-slice-send-feasibility.md`)

## Global Constraints

- Printer is fixed: `Bambu Lab P1S 0.4 nozzle`. Bed 256 x 256 x 256 mm; models are centred at (128, 128), min z = 0.
- Option tables (id -> profile name), exact strings:
  - filament: `pla_basic` -> `Bambu PLA Basic @BBL P1S 0.4 nozzle` (default); `pla_silk_plus` -> `Bambu PLA Silk+ @BBL P1S 0.4 nozzle`; `pla_matte` -> `Bambu PLA Matte @BBL P1S 0.4 nozzle`; `petg_hf` -> `Bambu PETG HF @BBL P1S 0.4 nozzle`
  - quality: `standard` -> `0.20mm Standard @BBL X1C` (default); `fine` -> `0.16mm Optimal @BBL X1C`; `draft` -> `0.28mm Extra Draft @BBL X1C`
  - plate: `textured_pei` -> `Textured PEI Plate` (default); `cool` -> `Cool Plate`; `smooth_pei` -> `High Temp Plate`
  - supports: `off` (default) -> `enable_support` `'0'`; `tree` -> `enable_support` `'1'`, `support_type` `'tree(auto)'`. Engine option values are passed as STRINGS (a numeric 1 was silently ignored in the spike).
- Limits: `MAX_TRIANGLES = 150_000`; slice timeout 900 s; one slice at a time; finished jobs kept 1800 s; only the latest finished job keeps its file.
- The slicer is optional everywhere: nothing may raise at import or at build when Node, the engine or the profiles are missing; `available()` reports it.
- No secrets in the repo or the page. All `/api/slice*` routes except `GET /api/slice/options` require the `X-Passcode` header and share the existing wrong-passcode throttle.
- Phone UI rules from the existing page: controls >= 44 px tall, single column at 390 px, no alert/confirm/prompt, messages in `#msg`.
- Repo rules (CLAUDE.md): PROGRESS.md entry after each task with an honest verification level; keep TASKS.md in sync; never claim a print or a Render run that did not happen.
- Not in scope: sending to the printer, AMS colours, other printers/nozzles, Docker.

## Review Focus

1. Model not centred or partly off the bed -> must never produce a file with extruding moves outside 0..256 (Task 1 `test_check_gcode_rejects_off_bed`, `test_prepare_centres_model`).
2. Engine ignores an option silently (wrong filament / plate / supports in the output) -> job fails with a clear reason (Task 1 `test_check_gcode_rejects_setting_mismatch`).
3. Engine missing or crashing on Render -> page shows "Slicer unavailable" / the failure text, Generate still works (Task 2 `test_options_when_unavailable`, Task 3 browser test).
4. Phone locks or connection drops mid-slice -> result still downloadable when the page comes back (Task 2 `test_job_survives_and_file_downloads`, Task 3 polling resumes from a saved job id).
5. Too-large or malformed STL upload -> 413 / 400 before the engine runs (Task 2 tests).

### Task 1: slicer core (`slicing.py`, `slicer/`)

**Files:**
- Create: `image3d/slicing.py`, `image3d/slicer/slice_job.js`, `image3d/slicer/package.json` (private, dependency `orcaslicer-addon` exactly `0.1.0`), `image3d/slicer/package-lock.json`, `image3d/slicer/install.sh`, `image3d/slicer/.gitignore` (`node_modules/`, `resources/`, `.node/`)
- Test: `image3d/tests/test_slicing.py`

**Interfaces - Produces** (`slicing`):
- `OPTIONS: dict` - the four tables above as `{"filament": [{"id","label","profile"},...], "quality": [...], "plate": [...], "supports": [...]}`, first entry is the default.
- `available() -> bool` - Node found (`slicing.node_path()`: `image3d/slicer/.node/bin/node` if present, else `node` on PATH), `slicer/node_modules/orcaslicer-addon` present, and `slicer/resources/profiles/BBL.json` present.
- `prepare_stl(data: bytes) -> tuple[bytes, dict]` - binary STL only. Raises `SliceError` (subclass of `ValueError`, `.status` 400 or 413) for: not a binary STL / truncated (400), zero triangles (400), more than `MAX_TRIANGLES` (413, message says the limit), any bbox side over 256 (400, "does not fit the 256 mm bed"). Returns the STL translated so the XY bbox centre is (128, 128) and min z is 0, and `{"triangles": n, "size_mm": [x, y, z]}`.
- `settings_for(choice: dict) -> dict` - `{"filament","quality","plate","supports"}` ids (missing keys -> defaults; unknown id -> `SliceError` 400) to `{"printer", "filament", "process", "options": {...strings...}}`.
- `check_gcode(gcode: str, settings: dict) -> dict` - raises `SliceError` (status 500) naming the first failed check: `printer_model` is `Bambu Lab P1S`; `nozzle_diameter` starts with `0.4`; `filament_settings_id` contains the filament profile; `print_settings_id` equals the process; `curr_bed_type` equals the plate; `enable_support` matches; every `G1` line that has both an `E` word with a positive value and X or Y after the first `; FEATURE:` line stays within 0 <= X <= 256 and 0 <= Y <= 256. Returns `{"print_time": "<text from '; model printing time: ...; total estimated time: <this>'>", "filament_g": float, "layers": int}`.
- `run_slice(stl: bytes, choice: dict, workdir: str, timeout=900) -> tuple[str, dict]` - prepare, write `model.stl`, run `node slicer/slice_job.js <in> <out> <settings.json>` (cwd `image3d/slicer`, `subprocess.run`, capture output, timeout), read `Metadata/plate_1.gcode` from the output zip, `check_gcode`, return (path to `model.gcode.3mf`, summary incl. `triangles`, `size_mm`, chosen labels). Engine failure / timeout / missing output -> `SliceError` 500 with the last 300 characters of engine output; the output file is deleted on any failure.
- `slice_job.js <input.stl> <output.gcode.3mf> <settings.json>`: `initialize({resourcesPath: <slicer/resources>, printerProfiles:[printer], filamentProfiles:[filament], processProfiles:[process]})`, `slice({input, output, printerProfile, filamentProfile, processProfile, options})`; prints one last line `RESULT {"ok":true,...}` or `RESULT {"ok":false,"error":"..."}`; exit code 0 / 1. Engine debug lines go to stderr or are left as-is; Python only parses the `RESULT` line.
- `install.sh` (bash, run from `image3d/`): (1) if no `node` on PATH and no `slicer/.node/bin/node`, download Node v22 LTS linux-x64 tarball from nodejs.org into `slicer/.node`; (2) `npm ci --omit=dev` in `slicer/`; (3) fetch `resources/profiles/BBL` and `resources/profiles/BBL.json` from `https://github.com/SoftFever/OrcaSlicer` at the pinned commit (sparse, blob-filtered clone into a temp dir, then copy) into `slicer/resources/profiles/`; (4) print `SLICER INSTALL: ok` or `SLICER INSTALL: failed at <step>`; **always exit 0**. Idempotent.

### Task 2: server job API

**Files:**
- Modify: `image3d/server.py`; Test: `image3d/tests/test_server.py` (add), reuse its fixtures.

**Interfaces - Produces:**
- `server.SLICER = slicing.run_slice` and `server.SLICER_AVAILABLE = slicing.available` (module attributes tests replace).
- `GET /api/slice/options` (no passcode) -> `{"available": bool, "limits": {"max_triangles": 150000}, "options": slicing.OPTIONS without the `profile` fields}`.
- `POST /api/slice` multipart: `model` (file, binary STL), optional form fields `filament`, `quality`, `plate`, `supports`. Guarded by the existing `GenerateGuard` (extend it to every `/api/slice` POST and every `/api/slice/<id>...` GET; `IMAGE3D_PASSCODE` must be set, `HF_TOKEN` is NOT required for slice routes). 503 `{"detail":"slicer unavailable on this server"}` when not available; 409 `{"detail":"a slice is already running"}` when one is queued/running; `SliceError` from `prepare_stl` / `settings_for` raised synchronously -> its status and message; otherwise 202 `{"job": "<id>"}` and the slice runs in a background thread.
- `GET /api/slice/{id}` -> `{"state": "running"|"done"|"failed", "detail": str, "summary": {...}|null, "elapsed_s": int}`; 404 for unknown / expired ids.
- `GET /api/slice/{id}/file` -> the `.gcode.3mf` bytes, `Content-Type: application/octet-stream`, `Content-Disposition: attachment; filename="model.gcode.3mf"`; 404 unknown; 409 if not done.
- Job store: dict guarded by a lock; ids from `secrets.token_urlsafe(8)`; each job owns a `tempfile.mkdtemp` directory removed when the job expires (1800 s after finishing, swept on every slice request) or when a newer job finishes; injectable clock (reuse `server.CLOCK`).

- Consumes: Task 2 routes; existing `I3DApp.exportStl()`, passcode field `#gen-pass`, wake-lock helpers, `#msg`.

**Behaviour:**
- On load in server mode, `GET api/slice/options`; hide `#slice-panel` entirely when not in server mode; when `available` is false show the panel with only the text "Slicer unavailable on this server"; otherwise fill the four selects from the response (labels from the server, first = default) and show "Bambu P1S, 0.4 mm nozzle".
- `#btn-slice` is disabled with a hint when there is no model, when the model has more than `max_triangles` triangles ("Model too detailed to slice here (N triangles, limit 150,000) - generate a lighter model"), or when any piece is not closed ("Model is not closed - slicing may fail" is a warning only, not a block).
- Slice: POST the STL from `I3DApp.exportStl()` as `model.stl` with the four fields and the passcode header; hold the wake lock; save the job id in `sessionStorage` (try/catch); poll `GET api/slice/{id}` every 3 s showing "Slicing... about 3 minutes on the free server; keep this screen open (Ns)"; on `done` show `#slice-result` ("Print time 1h 3m - 39 g - 348 layers - PLA Basic, 0.20 mm, Textured PEI") and enable `#btn-slice-download`; on `failed` show the detail in `#msg`. On page load, if a saved job id exists, resume polling it (404 clears it silently).
- Download: `fetch` the file with the passcode header -> Blob -> `<a download="model.gcode.3mf">`.
- Editing the model after a slice hides `#slice-result` (the file no longer matches the model).
