# Image3D (photo -> 3D -> STL editor) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phone-friendly web page that opens (or generates from a photo) a 3D mesh, lets Jacob delete pieces, resize, orient and cut it, and exports a printable STL.

**Architecture:** Pure mesh maths in dependency-free JS modules that run in Node (tests) and the browser. One page (`image3d/index.html`) built into a single file that is both a claude.ai artifact and the page a small FastAPI app on Render serves; the app adds `/api/generate`, which forwards a photo to a Hugging Face Space.

**Tech Stack:** Vanilla JS (UMD modules, same style as `gui/js/`), vendored three.js r-current from `gui/vendor/`, Python 3 + FastAPI + gradio_client, pytest (+ Node, Playwright).

**Spec:** `docs/superpowers/specs/2026-11-11-image3d-design.md`

## Global Constraints

- Used on a phone: controls at least 44 px tall, single-column layout at 390 px width, no hover-only actions.
- Units are millimetres. Bed limit 256 x 256 x 256 mm.
- Mesh format everywhere: a **shell** `{v: [x,y,z,...], t: [i,j,k,...]}` with shared (welded) vertices, same as `gui/js/geom.js`. A **model** is an array of shells (pieces).
- JS modules use the UMD wrapper from `gui/js/geom.js`, exporting to `root.I3D.<name>`; no npm dependencies.
- No secrets in the repo or the page: `HF_TOKEN` and `IMAGE3D_PASSCODE` are environment variables only.
- Artifact rules: no `fetch` to other hosts, no `alert/confirm/prompt`, downloads only through the `downloads` capability; so the page must work with `/api/*` absent and must fall back between download methods.
- Repo rule (CLAUDE.md): after each task, add a PROGRESS.md entry with an honest verification level, tick TASKS.md, commit.
- Not in scope: sculpting, booleans/holes, merging pieces, colours / 3MF, sending to the printer.

## Review Focus

1. A generated GLB with thousands of tiny loose fragments: piece list must stay usable (list only the 30 largest, "Remove small bits" tool) - Task 1 test `test_drop_small_pieces`.
2. A GLB using Draco / meshopt compression: clear message "this file is compressed", state unchanged - Task 2 test `test_glb_compressed_rejected`.
3. A non-closed (open) mesh from the generator: cut still works without crashing, check shows amber, export still allowed - Task 1 test `test_cut_open_mesh_no_throw`.
4. A model whose units are metres (GLB is ~1 unit tall): on open, auto-scale so the longest side is 100 mm and say so - Task 3 browser test `test_open_scales_to_100mm`.
5. Wrong or missing passcode, and Space quota/busy errors: 401 / 503 with a plain `detail` message the page shows - Task 4 tests.

### Task 1: `mesh.js` + `stl.js` (pure maths)

**Files:**
- Create: `image3d/js/mesh.js`, `image3d/js/stl.js`
- Test: `image3d/tests/test_mesh.py` (runs Node snippets like `gui/tests/test_model.py`; no three.js shim needed)

**Interfaces - Produces** (`I3D.mesh`):
- `weld(positions: number[], tol=1e-5) -> shell` - triangle soup (9 numbers per triangle) or indexed input `{v,t}` to a welded shell; drops degenerate triangles.
- `split(shell) -> shell[]` - connected pieces (by shared vertices), largest volume first.
- `bbox(model) -> {min:[x,y,z], max:[x,y,z], size:[x,y,z]}`
- `volume(shell) -> number` (signed-tetra sum, absolute value), `isClosed(shell) -> boolean` (every edge used exactly twice, opposite directions).
- `scale(model, k) -> model`, `scaleToLongest(model, mm) -> model`, `rotate90(model, axis: 'x'|'y'|'z') -> model`, `layFlat(model) -> model` (min z = 0, centred on x/y = 0).
- `removePiece(model, index) -> model`, `keepLargest(model) -> model`, `dropSmall(model, fraction=0.01) -> model` (drops pieces whose bbox diagonal < fraction of the model's).
- `cut(model, axis, value, keep: 'above'|'below') -> model` - clips each shell by the plane, caps each closed cut loop (ear-clipping in the plane; nested loops become holes by containment depth), re-welds. Pieces entirely removed disappear. Throws `Error('cut removes everything')` if the result is empty.
- All functions are pure (return new arrays).

**Interfaces - Produces** (`I3D.stl`):
- `write(model, name='image3d') -> Uint8Array` (binary STL, all pieces, computed normals).
- `read(bytes: Uint8Array) -> number[]` (triangle soup; binary or ASCII).

### Task 2: file readers `glb.js`, `obj.js`

**Files:**
- Create: `image3d/js/glb.js`, `image3d/js/obj.js`, `image3d/tests/make_samples.py` (writes `image3d/tests/samples/two_cubes.glb`, `.obj`, `.stl` deterministically; samples are committed)
- Test: `image3d/tests/test_readers.py`

**Interfaces - Produces:**
- `I3D.glb.read(bytes: Uint8Array) -> number[]` triangle soup in the file's units. Handles: binary GLB container, embedded BIN chunk, `POSITION` float accessors, indices of any integer type or none, triangle mode only, node hierarchy transforms (matrix or TRS), multiple meshes/primitives. Converts glTF Y-up to Z-up (x, y, z) -> (x, -z, y). Throws `Error('compressed')` when `extensionsRequired` includes `KHR_draco_mesh_compression` or `EXT_meshopt_compression`; throws `Error('not a GLB file')` on bad magic.
- `I3D.obj.read(text: string) -> number[]` triangle soup; fan-triangulates polygons; supports negative indices and `v/vt/vn` forms.
- `I3D.readAny(name: string, bytes: Uint8Array) -> number[]` in `glb.js`'s sibling `image3d/js/readany.js`: dispatch on extension (`.glb`, `.obj`, `.stl`); throws `Error('unsupported file')` otherwise.

### Task 4: Render service

**Files:**
- Create: `image3d/server.py`, `image3d/requirements.txt` (`fastapi`, `uvicorn[standard]`, `python-multipart`, `gradio_client`), `render.yaml` (one free Python web service `image3d`, `rootDir: image3d`, build `pip install -r requirements.txt`, start `uvicorn server:app --host 0.0.0.0 --port $PORT`, env vars `HF_TOKEN` and `IMAGE3D_PASSCODE` with `sync: false`, `HF_SPACE` default `tencent/Hunyuan3D-2.1`, `HF_API_NAME` default empty), `image3d/DEPLOY.md` (phone-friendly steps)
- Test: `image3d/tests/test_server.py` (FastAPI TestClient; `pytest.importorskip('fastapi')`)

**Interfaces - Produces:**
- `GET /` -> `image3d.html`; `GET /api/health` -> `{"ok": true, "space": <HF_SPACE>}`.
- `POST /api/generate` multipart: `image` (file, <= 10 MB, content type image/*), header `X-Passcode`. Returns `model/gltf-binary` bytes. Errors as JSON `{"detail": "..."}`: 401 wrong/missing passcode (constant-time compare), 400 not an image, 413 too large, 503 Space busy / quota / asleep (message passes through the Space's reason), 500 if `IMAGE3D_PASSCODE` or `HF_TOKEN` is unset ("server not configured").
- `server.generate_glb(image_bytes: bytes, filename: str) -> bytes` - the single swappable generator function; module-level `GENERATOR = generate_glb` so tests replace it. Implementation: `gradio_client.Client(HF_SPACE, token=HF_TOKEN)`; if `HF_API_NAME` is empty, pick the first endpoint from `client.view_api(return_format='dict')` whose parameters include an image/file input and whose name contains `generat` or `shape`; walk the result for the first path ending `.glb` and return its bytes. Runs in a worker thread (`run_in_threadpool`), timeout 300 s.
